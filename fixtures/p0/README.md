## Live fixture (P0-2)

Local HTTPS origins used by the tests:

| Node | Origin | Cert / key | Node identity |
|---|---|---|---|
| A | `https://alice.example:8443` | `.p0-tls/alice.crt` / `.key` | `.p0-tls/nodes/alice.json` |
| B | `https://hana.example:8444` | `.p0-tls/hana.crt` / `.key` | `.p0-tls/nodes/hana.json` |

`.p0-tls/` is generated by `scripts/tls-fixture.mjs` and **gitignored**; it contains a disposable CA, leaf certs, test ed25519 node keys, and `trust.json` (origin → public JWK + SPKI pin). Never reuse it outside tests.

```bash
pnpm tls:fixture
node scripts/serve-node.mjs --name alice --port 8443 --client-dist apps/playground/dist
node scripts/serve-node.mjs --name hana  --port 8444
```

Clients resolve `alice.example` / `hana.example` to 127.0.0.1 via a test-only resolver (`/etc/hosts` or Chrome host-resolver rules). The `.example` domains plus loopback mapping are explicit test exceptions; production blocks local/private targets (SSRF / DNS-rebinding guard).

## Scripts

| Script | Purpose |
|---|---|
| `scripts/tls-fixture.mjs` | disposable CA, leaf certs, node keys, trust anchors |
| `scripts/serve-node.mjs` | HTTPS node: signed descriptor, `world.json`, `/arrive` + `/arrive/consume`, static client |
| `scripts/live-conformance.mjs` | live protocol suite (strict CA): descriptors, token replay/expiry, unreachable, timeout, trust mismatch |
| `scripts/e2e-p0.mjs` | live browser E2E: actual portal UI confirm, 10 jumps, rollback, prefetch budget, whitelist |

```bash
pnpm test:p0          # mock 44/44 (2 worlds × 22)
pnpm test:live        # live node protocol 12/12
pnpm test:hardening   # rate limit, session quota, room-full, private, key rotation
P0_LIVE=1 pnpm build && P0_LIVE=1 pnpm test:e2e
pnpm report:p0        # unified mock/live report
pnpm p0:up            # one-click two-node launcher
```
