# brand assets

| File | Use |
|---|---|
| `choroweave-mono.svg` | monochrome mark for light backgrounds (source: Inceptless `assets/projects/choroweave-mono.svg`) |
| `choroweave-mono-inverse.svg` | same mark, white strokes, for dark backgrounds |

The mark is a portal motif ("Choroweave — Portal"). It is a brand asset of Inceptless and is excluded from the open-source licences; see [`LICENSES/LicenseRef-Inceptless-Brand.txt`](../../LICENSES/LicenseRef-Inceptless-Brand.txt). Do not alter proportions or the portal geometry; color inversion is the only variant kept here.

README uses a `<picture>` element so GitHub picks the correct variant for light/dark theme.
