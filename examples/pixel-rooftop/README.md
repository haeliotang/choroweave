# Pixel Rooftop · flagship example world (P1)

> A pixel-art Japanese apartment rooftop at dusk: concrete parapet, a low table with red cushion stools, an old radio on the table — click to play lo-fi; on the north wall, a glowing door leads to another world, "Neon Alley".
> Spec sources: [`docs/en/04-spatial-hyperlink-protocol.md`](../../docs/en/04-spatial-hyperlink-protocol.md) (SHP v0.1), [`docs/en/03-architecture.md`](../../docs/en/03-architecture.md) (World Bundle and runtime). Chinese version: [`README.zh-CN.md`](README.zh-CN.md).

## What is in this directory

| File | Purpose |
|---|---|
| [`world.json`](world.json) | World Manifest — the public SHP contract. Signed with a **demo ed25519 key** (the private key was discarded after signing). |
| [`world.dsl.json`](world.dsl.json) | Compiler intermediate representation (Spatial-DSL) source; `parts` is a first-class field. Contains the tacitweave ISS snapshot and a reproducible `inputHash`. |
| `README.md` | This document (English). |
| `README.zh-CN.md` | Chinese version. |

**This directory contains JSON sources only.** `scene/world.glb`, `assets/*.glb`, `assets/*.ogg`, `preview/*.webp` are produced by the Chôra Compiler and are not distributed with the *plan repository*. Therefore asset digests in `world.json` are **placeholder content digests**, governed by the rule below; `scripts/validate.mjs` validates that rule and the signature, not files that have not been generated.

## How to enter (P0 manual path, no compiler)

1. After generating a bundle with the Chôra Compiler (P1+), or by placing this directory plus generated binaries on a static server:
   ```
   https://<host>/worlds/pixel-rooftop/world.json
   https://<host>/worlds/pixel-rooftop/scene/world.glb
   https://<host>/worlds/pixel-rooftop/assets/…
   ```
2. Open `https://<host>/worlds/pixel-rooftop/world.json` with the reference runtime (P0+). Plain static hosting is enough; **no room service is required** (single-player mode).
3. Spawn is `spawn_default` (south side of the rooftop, facing north). Entering the 2.5 m trigger zone in front of the door prefetches "Neon Alley"; clicking the door traverses (`handoff: cross-instance`).

## Experience script (matches the flagship demo in docs/06)

| Step | Action | Expected |
|---|---|---|
| 1 | Enter the world | Dusk warm light, city ambience (`ambient_hum`, 1 s fade-in) |
| 2 | Look at the radio on the low table | Radio becomes selectable (`play_lofi` bound to `onSelect`) |
| 3 | Click the radio | Lo-fi plays (`audio/lofi_loop.ogg`, 180 s); knob material changes |
| 4 | Click the string lights | Warm string lights toggle on/off (`lightsOn` is in the sync whitelist) |
| 5 | Walk toward the glowing door | Within 2.5 m, prefetch starts (manifest + preview + scene shell, ≤8 MiB) |
| 6 | Click the door | Confirmation card shows target realm `hana.example` → handshake → enter "Neon Alley" |
| 7 | Target unreachable | Source world stays interactive, error code shown; no black screen (rollback) |

## Generation (expected P1 command; not implemented yet)

```bash
# Requires the compiler and a provider (TRELLIS.2 weights are MIT by default); this repo contains no implementation code yet
chora compile ./world.dsl.json --out ./bundle --tier standard --sign ./key.json
```

After compilation, S9 `emit` writes real asset digests, `entry.sha256` and `bundleDigest`, and re-signs with the author key (replacing the demo signature here). Field/enum/cross-field consistency between `world.dsl.json` and `world.json` is validated by [`scripts/validate.mjs`](../../scripts/validate.mjs).

## Placeholder digest rule (example-specific)

The plan repository ships no binaries. When a file referenced by `assets[].path` / `portal.preview.image` does not exist, its `sha256` is generated by the following rule and verified by `scripts/validate.mjs`:

```
placeholderDigest(path) = sha256( UTF-8( "choroweave-example-placeholder\n" + path ) )
```

On a real build, S6 `generate` replaces it with the SHA-256 of the file bytes — **this rule is not part of the SHP protocol**; it only keeps a "signed manifest + no binaries" example repository verifiable. The `bytes` field is a pre-build estimate; actual size wins after a build.

## Validation and regression

```bash
node ../../scripts/validate.mjs        # repo self-check: schema / example / links / ADR / signature
```

From P1, this world is also a regression fixture for [`weave-check`](../../docs/en/04-spatial-hyperlink-protocol.md) (portal, handshake, capability negotiation, prefetch budget, rollback). Current conformance cases are listed in SHP §12.

## Privacy and access policy

The example world uses `open` access, `general` rating and allows visitors. The ISS snapshot exists only in `world.dsl.json` (`privacy.shareWithNode: false`) and is never uploaded to a node. The demo signing key was discarded; it only demonstrates that signatures are machine-readable, and **must not be used as any production identity**.
